## 📖 Description

<p align="center"><b>A simple personal portfolio website built with Bootstrap</b></p>

This is my personal portfolio website, created to showcase my background, education, technical skills, projects, and experience through a simple and modern interface.

The website is designed with a responsive layout and includes both light and dark themes for a comfortable browsing experience across different devices.

## 📌 Features

* Responsive design for desktop, tablet, and mobile devices.

* Light and dark theme with persistent theme preferences.

* Modern and minimal user interface.

* About section for personal information and background.

* Education section showcasing academic background.

* Experience section highlighting professional and organizational experience.

* Skills section with animated skill progress indicators.

* Projects section for showcasing selected projects.

* Contact section for contact information.

* Custom 404 page for unavailable pages.

* Smooth navigation between sections.

* Back-to-top button for easier navigation.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Bootstrap Icons
